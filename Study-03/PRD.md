# 상식 퀴즈 게임 PRD

작성일: 2026-09-08 · 형태: Artifact로 게시되는 웹 페이지

## 1. 개요

한국사, 과학, 지리, 예술과 문화 네 개 카테고리에 걸쳐 총 40개의 4지선다 상식 문제를 푸는 웹 기반 퀴즈 게임이다. 플레이어는 문제마다 정답 여부를 즉시 확인하고, 게임이 끝나면 최종 점수가 모든 플레이어가 함께 보는 공유 리더보드에 기록된다. 결과물은 별도 설치 없이 링크로 접속해 바로 플레이할 수 있는 단일 웹 페이지(Artifact)로 게시한다.

## 2. 목표

- 짧은 시간(약 5~10분) 안에 완결되는 가벼운 퀴즈 경험을 제공한다.
- 정답/오답을 즉시 알려주어 학습 효과와 게임의 재미를 동시에 준다.
- 공유 리더보드로 플레이어 간 경쟁 요소를 더해 재방문을 유도한다.

## 3. 사용자 흐름

1. **시작 화면** — 게임 소개와 규칙(40문제, 4개 카테고리, 즉시 피드백)을 간단히 보여주고, 리더보드에 표시할 닉네임을 입력받은 뒤 시작 버튼을 누른다.
2. **퀴즈 화면** — 40개 문제를 순서대로 한 문제씩 보여준다. 보기 4개 중 하나를 선택하면 즉시 정답 여부와 정답을 표시하고, 다음 문제로 넘어간다.
3. **결과 화면** — 총점, 카테고리별 정답 수를 요약해서 보여주고, 리더보드로 이동하거나 다시 플레이할 수 있는 버튼을 제공한다.
4. **리더보드 화면** — 모든 플레이어의 닉네임과 점수를 높은 점수 순으로 정렬해 보여주고, 방금 플레이한 결과가 몇 위인지 강조해서 보여준다.

## 4. 핵심 기능 명세

### 4.1 문제 구성

| 카테고리 | 문제 수 | 형식 |
| --- | --- | --- |
| 한국사 | 10 | 4지선다 |
| 과학 | 10 | 4지선다 |
| 지리 | 10 | 4지선다 |
| 예술과 문화 | 10 | 4지선다 |
| **합계** | **40** | |

문제 순서는 카테고리 단위로 묶지 않고 40문제 전체를 섞어서 출제한다. 재플레이 시에도 동일한 40문제는 유지하되, 매번 순서를 새로 섞어 반복 플레이의 지루함을 줄인다.

### 4.2 문제 진행 및 즉시 피드백

- 보기 4개 중 하나를 선택하면 그 즉시 정답/오답을 시각적으로 표시한다(정답은 초록색 계열, 오답 선택 시 빨간색 계열로 표시하고 실제 정답도 함께 보여준다).
- 정답을 고르기 전까지는 다음 문제로 넘어가지 않으며, 한 번 선택하면 답을 바꿀 수 없다.
- 화면 상단에 "현재 문제 번호 / 40" 형태의 진행률을 표시한다.
- 문제별 제한 시간은 두지 않는다(전체를 편하게 풀 수 있는 캐주얼 톤을 우선한다).

### 4.3 점수 계산

- 문제당 정답 1개 = 1점, 오답 = 0점으로 계산한다(문제 난이도에 따른 가중치는 두지 않는다).
- 총점(최대 40점)과 함께 카테고리별 정답 수(예: 한국사 7/10)를 결과 화면에 함께 보여준다.

### 4.4 공유 리더보드

- 모든 플레이어의 플레이 결과가 하나의 리더보드에 누적되어, 접속한 모든 사람이 동일한 순위표를 본다.
- 기록 항목: 닉네임, 총점, 카테고리별 정답 수, 플레이 시각.
- 정렬 기준은 총점 내림차순이며, 총점이 같으면 먼저 기록된 순서를 유지한다.
- 리더보드는 상위 N명(예: 상위 50명)까지 표시하고, 방금 플레이한 기록이 그 밖에 있어도 본인 순위는 별도로 알려준다.
- 닉네임 기준의 간단한 기록이며, 로그인·비밀번호 등 계정 시스템은 두지 않는다.

## 5. 콘텐츠(문제) 제작 계획

40개 문제는 Claude가 직접 작성한다. 카테고리별로 아래 기준을 따른다.

- 한국사 10문제, 과학 10문제, 지리 10문제, 예술과 문화 10문제.
- 특정 시기나 분야에 치우치지 않도록 각 카테고리 안에서 소재를 고르게 분산한다.
- 지나치게 지엽적인 지식보다는 일반 성인이 알 만한 상식 수준으로 난이도를 맞춘다.
- 오답 보기도 그럴듯하게 구성해 단순 소거법으로 풀리지 않도록 한다.
- 사실 관계(연도, 인물, 지명 등)는 게시 전에 한 번 더 검증한다.

## 6. 기술 사양

- Artifact 도구로 게시하는 단일 HTML 페이지(CSS·JS 포함)로 구현한다.
- 공유 리더보드는 모든 방문자가 같은 데이터를 봐야 하므로, Artifact의 공유 데이터 저장 기능을 사용해 플레이 기록을 서버 쪽에 저장한다(브라우저 로컬 저장소만으로는 다른 사람과 공유되지 않는다).
- 라이트/다크 모드를 모두 고려한 디자인으로 제작한다.
- 모바일과 데스크톱 화면 크기 모두에서 무리 없이 보이도록 반응형으로 만든다.

## 7. 설계 가정 및 결정 사항

아래는 이번 PRD 작성 과정에서 별도로 확인하지 않고 합리적으로 가정한 부분이다. 실제와 다르면 알려주시면 반영한다.

- 문제별 제한 시간 없음(전체 게임 완료까지의 시간 제한도 없음).
- 한 사람이 여러 번 플레이할 수 있고, 플레이할 때마다 리더보드에 새 기록이 추가된다(최고 기록만 남기지 않음).
- 닉네임 중복은 허용한다(같은 닉네임의 기록이 여러 개 쌓일 수 있음).
- 문제와 보기 순서는 매 플레이마다 무작위로 섞는다.

## 8. 범위 제외

- 회원가입/로그인, 소셜 공유 기능은 포함하지 않는다.
- 관리자가 문제를 직접 추가/수정하는 편집 화면은 포함하지 않는다.
- 문제 은행을 40개보다 늘리거나 카테고리를 추가하는 것은 이번 범위에 포함하지 않는다.

3. Artifact로 게임 페이지 제작 및 게시.
