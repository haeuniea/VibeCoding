---

여러 학생이 `/teacher-setup`으로 추가된 "내 기록 내보내기" 기능으로
받은 JSON 파일들을 읽어, 학생 간 성적을 비교하는 리포트를 만든다.

대상 폴더: ${ARGUMENTS}

- `${ARGUMENTS}`가 지정되면 그 폴더의 `*.json` 파일을 모두 사용한다.
- 비어 있으면 `.claude/teacher-data/submissions/`(실제 학생 제출 파일)을
  먼저 찾는다. 그 폴더가 없거나 비어 있으면
  `.claude/teacher-data/samples/`(`/teacher-mock-data`가 만든 테스트
  데이터)를 대신 사용하고, **샘플 데이터로 만든 데모 리포트임을 결과
  최상단에 명시한다.**
- 두 폴더 모두 없거나 비어 있으면 중단하고, `/teacher-setup`으로 내보내기
  기능을 먼저 만들고 학생 파일을 모으거나 `/teacher-mock-data`로 샘플을
  생성하라고 안내한다.

## 절차

1. 대상 폴더의 모든 `*.json` 파일을 읽는다. 각 파일이
   `{ studentName, history: [...] }` 스키마를 갖추고 있는지 확인한다.
   스키마가 어긋난 파일은 목록에서 제외하고 파일명과 이유를 기록해
   나중에 보고한다.
2. 학생별로 다음을 계산한다.
   - 총 게임 수, 평균 점수, 최고 점수
   - 전체 정답률: 모든 기록의 `correctAnswers` 합 / `totalQuestions` 합
   - 카테고리별 정답률: 모든 기록의 `categoryScores`를 합산
   - 최근 게임 점수 추이(시간순 정렬 후 상승/하락/横보합 판단)
3. 학생 간 비교표를 만든다 — 평균 점수 기준 내림차순 정렬. 각 학생의
   카테고리별 정답률을 반 전체 평균과 비교해 강점/약점 카테고리를
   표시한다(반 평균보다 10%p 이상 낮으면 약점, 높으면 강점으로 표시).
4. 반 전체 통계를 계산한다 — 참여 학생 수, 반 평균 점수, 카테고리별
   반 평균 정답률.
5. 특이사항을 짚는다 — 참여 기록이 1개뿐이라 추세를 판단하기 이른
   학생, 최근 들어 점수가 뚜렷이 하락한 학생, 특정 카테고리에서 반
   전체가 유독 약한 경우 등.
6. 결과를 파일로 저장할지 사용자에게 확인한다. 동의하면
   `.claude/teacher-data/reports/report_YYYYMMDD_HHMMSS.md`로 저장한다
   (`.claude/teacher-data/reports/` 폴더가 없으면 새로 만든다).

## 출력 형식

- 데이터 출처 한 줄 안내(실 데이터 폴더 경로, 또는 "샘플 데이터 기반
  데모" 명시)
- 제외된 파일이 있으면 그 목록과 이유
- 학생별 비교표(이름, 게임 수, 평균 점수, 최고 점수, 전체 정답률,
  강점/약점 카테고리)
- 카테고리 × 학생 정답률 매트릭스
- 반 전체 통계 요약
- 특이사항 목록
- (저장에 동의한 경우) 저장된 리포트 파일 경로

사용자가 저장에 동의하기 전까지는 어떤 파일도 새로 쓰지 않는다.
