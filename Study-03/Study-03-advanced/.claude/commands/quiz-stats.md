description: questions.js 문제 풀의 구성 통계(카테고리·난이도·정답 분포)를 관리한다
---

`questions.js`의 문제 풀을 분석해 구성 통계를 보여준다. 게임을 플레이해서
쌓이는 개인 기록(`localStorage`의 `quizGameHistory`, 브라우저의 "📊 내
통계" 화면에서 보이는 값들)은 브라우저 안에만 저장되어 있어 이 명령에서는
조회할 수 없다 — 이 명령은 문제 "콘텐츠" 자체의 통계를 다룬다.

대상: ${ARGUMENTS}

- `${ARGUMENTS}`가 비어 있으면 전체 문제 풀을 대상으로 한다.
- `${ARGUMENTS}`가 지정되면 그 값과 `category`가 일치하는 문제만
  대상으로 한다. 일치하는 문제가 하나도 없으면 존재하는 category 목록을
  보여주고 사용자에게 확인한다.

## 절차

1. `questions.js`를 읽고 대상 문제를 추린다.
2. 전체 문제 수, id 최솟값·최댓값, id 누락·중복 여부를 확인한다.
3. category별 문제 수를 집계한다.
4. category별 difficulty(easy/medium/hard) 분포를 집계한다.
5. `correctAnswer` 값(0~3)의 전체 분포를 집계하고, 특정 보기로 쏠림이
   있는지 확인한다 (예: 4개 중 하나가 이례적으로 적거나 많음).
6. 각 category가 20문제 미만이면, 목표(카테고리당 20문제 이상 — 3단계
   3.5 항목) 대비 몇 개 부족한지 표시한다.

## 출력 형식

먼저 전체 요약(총 문제 수, id 범위, 누락·중복 여부)을 보여준다. 그다음
category × difficulty 표, `correctAnswer` 분포, 마지막으로 카테고리별
20문제 목표 대비 부족분을 보여준다. 파일을 수정하지 않는다 — 통계만
보여준다.
